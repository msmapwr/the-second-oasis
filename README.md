# 《第二绿洲》The Second Oasis

> 月球领土争夺 · 网页策略桌游 · 2 ~ 4 人对战

---

## 游戏简介

**《第二绿洲》** 是一款面向 2~4 人的回合制网页策略桌游。玩家分别扮演四个国家，在月球表面展开零和领土争夺。以掷骰为核心随机源，融合 **稳健 / 激进 模式选择**、**开发链连击** 的高风险博弈、**抢夺与崩坏** 的对抗熔断机制，以及 **发射序章** 的准入仪式。公共领土归零时，私有领土最高者获胜。

| 属性 | 说明 |
|------|------|
| 类型 | 网页策略桌游 |
| 人数 | 2 ~ 4 人 |
| 对局时长 | 约 15 ~ 30 分钟 |
| 运行环境 | Chromium 内核浏览器（Chrome / Edge 等） |
| 当前版本 | **v1.0** |
| 技术栈 | TypeScript + Vite + Canvas 2D + WebSocket |
| 测试覆盖 | 37 文件 / 291+ 测试用例 |

## 核心机制

### 基础规则

- **公共领土**：初始 100 点，归零即终局
- **私有领土**：各玩家独立积累，终局时最高者获胜
- **回合制**：每轮每位玩家依次选择模式 → 掷骰 → 占领 → 结算

### 模式选择

| 模式 | 骰子 | 收益 | 风险 |
|------|------|------|------|
| **稳健** | 1 颗 (1~6) | 稳定占领 1~6 | 无风险 |
| **激进** | 2 颗 (2~12) | 高收益占领 2~12 | 总和 ≤6 则倒扣回公共 |
| **不开发** | — | 维持节奏 | 不触发开发链 |

### 开发链

连续掷出对子触发连击：

| 连续对子 | 效果 |
|----------|------|
| 第 1 次 | **开发** → 本回合领土 ×2 |
| 第 2 次 | **大开发** → 本回合领土 ×3 |
| 第 3 次 | **开发过度** → 私有清零 + 标记荒地 + 需重新发射 |

### 抢夺与崩坏

- **抢夺**：占领溢出公共池时触发，由发起者 vs 私有最高者掷骰裁决，仅触发 **1 次**
- **崩坏**：第 2 次触发抢夺时升级为崩坏，全员受损，系数 x 初值 2 每次 +1

### 发射

- 首轮序章：每位玩家掷双骰 ≥7 即发射成功，奖励 +2 私有领土
- 全员发射成功后才进入主循环
- 开发过度清零后需重新发射

### v1.2 变体包（可选启用）

- **公敌税 Leader Tax**：每轮结束对唯一领先者征税 1 点回流公共
- **顺位轮换 Rotating Start**：每轮首位玩家轮换，消除先手优势
- **枯竭冲刺 Scarcity Sprint**：公共 ≤30 时正向占领额外 +2
- **复仇突袭 Revenge Raid**：被抢/崩坏损失最大者获复仇令牌（默认关闭）

## 快速开始

### 一键脚本（推荐）

| 脚本 | 平台 | 用途 |
|------|------|------|
| `scripts/deploy.bat` | Windows | 自动检查环境 → 装依赖 → 类型检查 → 构建 |
| `scripts/deploy.sh` | macOS / Linux / Git Bash | 同上 |
| `scripts/start.bat` | Windows | 交互式菜单：开发 / 联机 / 预览 / 测试 |
| `scripts/start.sh` | macOS / Linux / Git Bash | 同上 |

> **Windows 用户**：双击 `scripts\deploy.bat` 即可完成部署，双击 `scripts\start.bat` 即可启动。

### 环境要求

- **Node.js** >= 18
- **包管理器**：npm（已锁定）

### 命令行安装与运行

```bash
# 克隆项目
git clone <repo-url>
cd the-second-oasis

# 安装依赖
npm install

# 开发模式（Vite HMR）
npm run dev

# 类型检查
npm run typecheck

# 运行测试
npm test

# 测试覆盖率
npm run test:coverage

# 构建生产版本
npm run build

# 预览构建结果
npm run preview

# 启动联机服务器 + 客户端（完整联机体验）
npm run dev:full
```

### 运行联机服务器

```bash
# 单独启动 WebSocket 服务器（端口 9528）
npm run server
```

## 数据流

### 本地对局
```
AppController.Run()
  → InputGate（玩家输入）
  → GameStore.PlayTurn()
  → GameState（核心逻辑）
  → AnimationCoordinator（动画编排）
  → Renderers + Audio（画面 + 音效）
```

### 联机对局
```
客户端 AppController
  → NetworkGameStore（本地代理）
  → WebSocketClient
  → Server:GameRoom（GameState 权威）
  → 广播到各客户端
```

### AI 对局
```
AIDirector.PlayForCurrentPlayer()
  → AIPlayer.DecideMode()
  → DecisionMaker（混合决策）
  → Evaluator（局面评估）+ Simulator（前瞻模拟）
```

## AI 系统

- **6 档难易度**（0~5）：从随机乱来到精英博弈
- **四维性格模型**：攻击性 / 风险偏好 / 记忆性 / 合作性
- **敌意记忆系统**：AI 会"记仇"，被抢后针对性报复
- **决策可解释**：每步决策附带透明日志（ModeDecisionTrace）
- **混合决策引擎**：概率加权评估 + 浅层前瞻模拟 + 性格矫正

---

## 视觉与动效

- **像素风主题**：参考 Minecraft 风格，方块化极简
- **配色方案**：深空蓝绿 (`#0e7c86`) + 月壤灰
- **三层 Canvas 渲染**：星空背景 → 月球沙盘 → 特效层
- **动效系统**：骰子翻滚、领土增减、席位脉冲、数字弹出、崩坏震屏
- **响应式布局**：支持桌面 + 移动端，768px 断点自适应
