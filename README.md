# 《第二绿洲》（The Second Oasis）

> 月球领土争夺 · 回合制网页策略桌游 · 2～4 人对战

## 游戏简介

《第二绿洲》是一款以月球殖民为背景的回合制网页策略游戏。

玩家扮演不同国家的月球开发势力，在有限资源、随机事件和其他玩家竞争中建立自己的领土。

你的目标：

- 开拓月球区域
- 管理风险与收益
- 通过开发链扩大优势
- 与其他国家争夺关键资源
- 在终局结算中成为最大的月球势力

## 核心玩法

### 🌕 领土争夺

玩家通过每回合行动开发月球区域。

公共领土会随着竞争逐渐减少，当资源耗尽时进入最终结算阶段。

### 🎲 风险选择

每回合玩家需要在不同策略之间选择：

- **稳健开发**：收益稳定，风险较低
- **激进开发**：高收益，同时承担失败风险
- **暂停发展**：保存实力，等待机会

### 🔗 开发链

连续成功开发可以触发连锁收益：

- 普通开发
- 大规模开发
- 过度开发风险

扩张越快，也意味着更高的不确定性。

### ⚔️ 抢夺与崩坏

玩家之间可以争夺领土。

同时，崩坏机制会限制领先者无限扩大优势，让落后玩家保持翻盘机会。

### 🚀 发射序章

每局游戏从月球发射阶段开始。

成功完成发射后，玩家正式进入殖民竞争。

## 快速开始

```bash
git clone <repo-url>
cd the-second-oasis
npm install
npm run dev
```

其他命令：

```bash
npm run typecheck   # 类型检查
npm test            # 运行测试
npm run build       # 构建生产版本
```

- 策略决策

转化为更容易体验的网页游戏。

未来计划包括：
