遵照为你制定的 **Vue 3 + TypeScript + Tailwind CSS + Pixi.js** 技术选型方案 ，我为你梳理了《第二绿洲》（The Second Oasis）的整体工程目录架构。

这套架构遵循“逻辑引擎与 UI / Canvas 强解耦”的设计原则 ：`src/engine/` 中的纯 TypeScript 状态机不依赖任何 DOM 或 Vue 语法，既方便进行单元测试 ，也能在后续局域网联机时直接同步给 Node.js 服务端复用 。

## 🧩 核心模块职责分工

1. 
**`src/engine/`（规则逻辑引擎）**：
* 采用 TypeScript 状态模式（State Pattern）构建 。


* 负责处理所有的🎲骰子结算、激进模式事故判定、抢夺 PK 逻辑以及崩坏公式递增 。




2. **`src/canvas/`（Pixi.js 视觉层）**：
* 负责高性能的 100 格圆环/网格渲染、荒地灰色遮罩、连续对子发光粒子以及全屏红警 Glitch 特效 。




3. **`src/stores/gameStore.ts`（Pinia 桥接）**：
* 充当 Engine 与 View 的同步中枢。Engine 触发 `emit('stateChange')`，Pinia 接收更新后，Vue 视图与 Pixi.js Canvas 同步完成重绘。


4. 
**`src/components/`（Tailwind Vue UI）**：
* 负责磨砂玻璃 HUD 面板 、战术控制台操作 、Monospace 终端日志流 以及弹出式的 PK 比大小动画窗口 。
