1游戏概览

一句话定位与关键属性。

《第二绿洲》是一款面向 2~4 人 的网页策略桌游。玩家分别扮演四个国家，围绕月球（公共领土）展开领土争夺。游戏以掷骰为核心随机源，融合稳健 / 激进策略选择、连击开发的风险博弈，以及由抢夺升级而来的崩坏熔断机制。当公共领土被瓜分殆尽，私有领土最多者获胜。

网页端运行 2 ~ 4 人 回合制 掷骰驱动 风险 / 收益博弈 公共池衰减

2游戏背景与主题

地球资源枯竭后，人类将目光投向月球——代号"第二绿洲"。四个国家率先具备登月能力，意图在月球表面抢占尽可能多的领土。然而月球公共领土有限，争夺必然走向零和：当最后一块公共领土被分配完毕，谁在私人物业上积累最多，谁就掌握了新文明的主动权。

主题基调：冷峻的太空殖民竞争 + 轻策略博弈。视觉上建议采用深空蓝绿 + 月壤灰的配色，与计划书主色一致。

3游戏目标与胜负

3.1 胜利条件 已裁定 Q1 / Q7

当 公共领土归零（= 0） 时游戏立即结束，私有领土数值最高 的玩家获胜。

  • 终局判定点：任何使公共领土变为 0 的步骤后（正常占领拿光、抢夺 r 回归后、崩坏公共 clamp 至 0）立即终局。
  • Q1 裁定：抢夺阈值 m = 0，即占领使公共领土 变为负数时才触发抢夺；公共恰好归零 = 终局，不进入抢夺流程。这保证了「归零即终局」规则的优先级与无歧义。

3.2 终局平局裁决 已裁定 Q7

若多人私有领土并列最高，进入加赛（Tiebreaker）：

  1. 仅平手者参与；每人掷双骰（和 2~12）。
  2. 双骰和最高者获胜；若仍多人并列最高，继续掷，无上限直至分出唯一胜者。
设计意图公共池是零和博弈的锚点：它越小，单次占领越容易溢出触发抢夺与崩坏，对局在后段会显著加速并趋于混乱。加赛用双骰（而非单骰）是 Q7 的明确裁定，方差更平滑、裁决更快。

3.3 失败 / 出局

常规情况下没有淘汰；但触发 开发过度（连续三次掷出对子，见 §9）时，该玩家私有领土清零并标记为"荒地"，需重新走"发射"流程后才能再次参与占领。荒地不计入任何玩家领土，也不回归公共领土。

荒地边界若终局时全员均为荒地（私有 = 0），则全员并列最高（=0），仍进入加赛决出唯一胜者——不会出现"无人获胜"的局面。

7基础机制：掷骰与占领

7.1 掷骰决定本回合应得领土 Q3 / C2

玩家选择模式后掷骰，生成本回合应得领土 RawGain：

模式骰数RawGain 计算是否可能为对子
稳健 Steady1 颗= 骰值（1~6）否（单骰无对子）
激进 Aggressive2 颗正常：= 双骰和（2~12）；若和 ≤ 6：= −和（倒扣）是（两骰相同）
不开发 None0 颗= 0（不掷骰）否（未掷骰）
C2 裁定 · 激进小对子激进掷出 (1,1)=2、(2,2)=4、(3,3)=6 时，既是对子（和≤6）又触发倒扣。两机制独立结算：对子仍触发开发链（连击 +1，倍率作用于 RawGain），倒扣使 RawGain = −和（为负），倍率再作用于该负值。例：(1,1) → 连击 +1（首次对子 ×2）→ M = −2 × 2 = −4，私有 −4、公共 +4。理由：对子就是对子，与点数大小无关；倒扣只改应得值的符号。

7.2 占领（Occupation）结算公式

本回合实际占领量 M = RawGain × Multiplier（Multiplier 来自开发链 §9；倒扣时 RawGain 为负，M 也为负）。结算分三种情形：

// 实际占领量（含倒扣与开发链倍率） M = RawGain × Multiplier // 情形 A：M ≤ 0（倒扣 / 不开发）→ 私有减少、公共回血，守恒，不溢出 Private' = max(0, Private − |M|) // 私有 clamp 至 0 Public' = Public + (Private − Private') // 公共只加实际扣量，严格守恒 IsOverflow = false // 情形 B：M > 0 且 M ≤ 公共剩余 → 正常占领 Public' = Public − M Private' = Private + M IsOverflow = false // 情形 C：M > 公共剩余 → 溢出（C1 裁定） m2 = M − Public // C1：溢出的是实际占领量 M，非原始 n Public' = 0 // 公共拿光 Private' = Private + Public // 仅拿到公共剩余部分 IsOverflow = true // 剩余 m2 进入抢夺 / 崩坏
举例公共剩 30，玩家激进掷出 (6,6)=12 且为第 1 次连续对子（×2）→ M = 12 × 2 = 24。溢出 m2 = 24 − 30 = −6？——注意：此处 24 > 30 不成立，故为情形 B（正常占领，公共 30→6）。若改为公共剩 10，则 m2 = 24 − 10 = 14 进入抢夺。可见 ×2 倍率会显著放大溢出概率。

8回合开局：模式选择

每回合开始时，玩家可选择以下三种模式之一。模式决定本次掷骰的风险与收益：

稳健模式 SAFE

只掷 1 颗 骰子，获得 1 ~ 6 领土。
永不倒扣、永不触发开发链（单骰无对子），收益低但稳定。

激进模式 RISK

掷 2 颗 骰子，获得 2 ~ 12 领土。
若点数的和 ≤ 6，则改为扣除相应点数并回归公共领土（私有 − 点数，公共 + 点数）。

不开发 NONE

完全不掷骰、不占领、无直接效果（Q3）。用于观望；因未掷出对子，会清零开发链连击（Q8）。

Q3 裁定 · "不开发"语义「不开发」是独立的第三种模式，不等于稳健：它完全不掷骰（RawGain = 0），因此既不产生占领，也不消耗随机源（联机同步关键，见 §13.2）。它与稳健的差异在于——稳健至少拿 1~6 领土，不开发则零收益但零风险。
Q8 裁定 · 不开发与连击虽然不开发无直接效果，但按 Q8「任何非对子结果都清零连击」，不开发 = 未掷出对子 = 中断连击。即：若你上一回合刚攒到第 2 次连续对子（×3 待用），本回合选不开发，则连击清零，下回合对子只能按"第 1 次"重新计。这是"不开发"的间接战术代价。

9连击机制：开发链

当玩家掷出两个相同数字（对子）时，触发开发链。链的长度取决于连续掷出对子的次数（连击计数 ConsecutiveDoubles，0~2）：

连续对子次数触发开发链倍率本回合 M 计算
0（非对子）—×1（无加成）M = RawGain × 1
第 1 次开发×2M = RawGain × 2
第 2 次（连续）大开发×3M = RawGain × 3
第 3 次（连续）开发过度—（清零）M 作废，私有清零 + 荒地

9.1 计数规则 Q4 / Q8 / C2

  • Q4 裁定（翻倍基数）：倍率作用于本回合应得领土 RawGain（即 M = RawGain × 倍率），不是私有总额翻倍。若按私有总额翻倍，玩家积累 50 后一次对子直接 100+ 锁胜，博弈深度崩塌；按 RawGain 翻倍更可控。
  • Q8 裁定（清零条件）：任何非对子结果都清零连击，含「不开发」模式。仅 Aggressive 双骰相同（含 (1,1)/(2,2)/(3,3)）算对子；Steady 单骰恒非对子；None 未掷骰恒非对子。
  • C2 裁定（小对子倒扣）：(1,1)/(2,2)/(3,3) 对子仍计入连击，但 RawGain 为负，倍率作用于负值（见 §7.1）。
高风险高回报连续对子是强力的滚雪球手段，但第三次会直接清零——是经典的"见好就收"博弈点。建议在 UI 上对"连续对子计数"做醒目提示。
开发过度处理触发第 3 次连续对子时：私有领土清零、标记"荒地"、状态置为 NeedsRelaunch、连击计数归 0，本回合不执行占领（应得被清零抹除），直接进入回合结束。该玩家下回合需重新发射（见 §12）。

10特殊机制：抢夺

当玩家 (p) 的占领使公共领土不足以支付实际占领量（公共 < 0，即 M > 公共剩余，Q1 裁定 m = 0）时，溢出部分 m2 触发抢夺，由 (p) 发起。仅在本局首次溢出时触发；其后溢出升级为崩坏（§11）。

10.1 抢夺触发与防守者

  • m2 计算（C1）：m2 = M − 公共剩余 = (RawGain × Multiplier) − 公共剩余。
  • 防守者：除发起者 (p) 外，当前私有领土最高者。并列时取 ID 最小者（确定性，便于联机复现）。

10.2 抢夺裁决流程 Q5 / C3 / C6

  1. 发起者与防守者各掷单骰 1~6（C6 裁定：裁决性质，快速分胜负）。
  2. 平手（Q5）：双方都重掷，直至分出高低（无上限）。
  3. 点数更高者为赢家；生成随机损耗 r = NextInt(1, m2)（即 0 < r ≤ m2）。
  4. 按方案 E 守恒（C3）结算：
// C3 方案 E：低者私有可能不足 m2，优先严格守恒 LowPrivate = 低者私有原值 Transfer = min(m2, LowPrivate) // 实际可转移量 r = min(r, Transfer) // r 受 Transfer 约束，避免越界 低者私有' = 低者私有 − Transfer // 扣至 0 为止 高者私有' = 高者私有 + (Transfer − r) 公共' = 公共 + r // r 回归公共池 // 守恒校验：−Transfer + (Transfer − r) + r = 0
要点抢夺本质是"盈家与当前霸主"对溢出领土的裁决；r 作为损耗回归公共池，使公共领土有微量回血可能（r > 0 时公共不会归零，故抢夺本身不终局）。低者私有为 0 时 Transfer = 0、r = 0，抢夺实质无效但仍记录掷骰历史。
限制抢夺只能被触发一次。同一局中第二次本应触发抢夺的溢出，不再走抢夺流程，而是直接升级为 崩坏（见 §11）。

11特殊机制：崩坏

当本局第二次（及以后）发生占领溢出时，系统进入崩坏状态——月球环境失衡，所有玩家共同受损。这是惩罚"过度争夺"的熔断阀。

11.1 崩坏结算公式 Q6 / C4 / C5

// Q6 裁定：总量守恒目标 = x · m2 TotalTarget = x × m2 PerCap = floor((x × m2) / 4) // 每位非发起者的随机损失上限 // 每位非发起者 i 独立随机损失（C4：私有不足则 clamp） RandomLoss_i = NextInt(0, PerCap) ActualLoss_i = min(RandomLoss_i, 私有_i) OthersSum = Σ ActualLoss_i // 发起者承担剩余缺口（Q6） InitRandomLoss = TotalTarget − OthersSum InitActualLoss = min(InitRandomLoss, 发起者私有) // C4：发起者亦不足则 clamp TotalLoss = OthersSum + InitActualLoss IsConserved = (TotalLoss === TotalTarget) // 仅当全员私有总和 < x·m2 时为 false // 公共领土变化（C5：clamp 至 0） Public' = max(0, 公共 − x) // 若 = 0 立即终局 NextX = x + 1 // 系数自增
Q6 裁定 · 分配逻辑每位非发起者独立随机损失 [0, floor((x·m2)/4)]，发起者承担剩余缺口 = (x·m2) − 其他玩家已损失之和。总量目标恒为 x·m2。仅当"全员私有总和 < x·m2"时无法严格守恒，此时 IsConserved = false 但避免任何玩家私有变负（C4）。
C5 裁定 · 公共边界崩坏使公共 = max(0, 公共 − x)。若当前公共已很小（如抢夺后公共 = r），减 x 会变负，此时 clamp 至 0 并立即触发终局（按 Q1，公共 = 0 即终局）。
设计意图崩坏系数 x 随次数递增（2 → 3 → 4 …），意味着反复触发会让公共池与私人池同步塌缩，加速终局并制造大洗牌。首次崩坏 x=2，平均损失目标 = 2·m2；第二次 x=3，以此类推。

12特殊回合：发射

发射是游戏唯一的序章回合，仅在第一轮开始时进行；所有玩家必须先"发射"飞船，才能进入后续的领土抢占。

规则说明
触发时机首轮开始；以及玩家触发开发过度后（重新发射）
发射条件掷双骰之和 ≥ 7 即发射成功（注意：发射用双骰但不触发倒扣，只看和）
发射奖励成功后私有领土 +2
失败处理发射失败者直接跳到下一玩家；下一回合继续尝试发射（无次数上限）
全员约束必须所有玩家都发射成功，占领阶段才开始
重新发射开发过度清零的玩家，需重新发射才能再次参与：仅该玩家走 LaunchPhase，掷 ≥7 成功 +2、解除荒地、恢复 Active
关联首轮发射与开发过度后重新发射规则完全一致（掷 ≥7 恢复资格，成功后 +2）。发射阶段不消耗"占领随机源"以外的额外逻辑，但发射双骰的调用顺序需纳入联机种子序列（见 §13.2）。

13.2 状态与随机数（A 优先级已落实）

  • 单一可信状态源：GameState 维护全局领土快照，所有模块为纯函数 / 无状态类，由状态机编排（确保联机多端一致）。
  • 可复现随机源 IRandomSource：Core 层不直接调用 Math.random。提供 DefaultRandom（单机）与 SeededRandom（mulberry32 算法，联机种子同步用）。关键不变量：不开发（None）模式不消耗随机源——保证联机时相同种子 + 相同调用序列 = 相同结果。
  • 开发链状态机：每玩家独立 DevChain 实例，连击计数跨回合持久化。

13.3 技术栈（已采用）

TypeScript（strict 全开）+ Vite + Vitest + Canvas 2D（画面）/ DOM（UI 面板）。Core 层零第三方运行时依赖。联机（C 优先级）将采用 WebSocket 房间 + 服务端权威结算，复用 SeededRandom 做种子同步。

A 优先级交付状态 · 已就绪核心逻辑代码位于 src/Core/，含 8 个模块（DiceRoller / Occupation / DevChain / Robbery / Collapse / Launch / GameEnd / GameState）+ 类型层 src/Types/ + 工具层 src/Utils/。全部规则已通过 115 个单元测试 + 严格类型检查（详见 §16）。

14术语表

公共领土
月球上所有玩家共享、可被瓜分的领土，初始 100，归零即终局（Q1：公共=0 不触发抢夺）。
私有领土
各玩家独立积累、决定胜负的最终数值，初始 0，永不为负。
占领
把 M 点领土从公共池转移到自己私有名下（M = RawGain × 倍率）。
RawGain
本回合应得领土：稳健=骰值；激进正常=双骰和、≤6 时为−和；不开发=0。
开发链
连续掷出对子触发的连击：第1次×2 / 第2次×3 / 第3次清零（开发过度）。
连续对子计数
ConsecutiveDoubles（0~2），任何非对子（含不开发）清零（Q8）。
抢夺
首次占领溢出时，发起者与私有最高者裁决溢出量 m2 的特殊机制（单骰裁决，仅触发一次）。
崩坏
第二次及以后溢出触发的全局惩罚，系数 x 随次数递增，全员随机受损。
m2
溢出量 = M − 公共剩余 = (RawGain × 倍率) − 公共剩余（C1）。
r
抢夺中回归公共的随机损耗量，0 < r ≤ m2（受 Transfer 约束）。
x
崩坏系数，初始 2，每次崩坏 +1，目标损失 = x·m2。
开发过度
连续 3 次对子触发，私有领土清零并标记荒地，需重新发射。
荒地
开发过度后私有领土的状态，不计数、不回归公共。
发射
首轮专属序章，掷 ≥7 成功方可参与占领，成功 +2；开发过度后需重新发射。
加赛
终局平局时，仅平手者掷双骰（2~12），高者胜；仍平手继续（Q7）。
不开发
第三种模式：完全不掷骰、不占领、无直接效果，但清零开发链连击（Q3 / Q8）。
