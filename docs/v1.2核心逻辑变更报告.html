二、关键代码位置与改动详情

2.1 公敌税结算

src/Core/GameState.ts ApplyLeaderTax()

  • 仅当 EnableLeaderTax && LeaderTaxBase > 0 时执行。
  • 统计所有 Active && IsLaunched 玩家，找出私有最高者。
  • 若存在并列最高（含 0），免税。
  • 实际扣税 min(LeaderTaxBase, Leader.PrivateTerritory)，加到公共池。
  • 在 PlayTurn 末尾、AdvanceToNextPlayer 之前调用，仅当本轮结束时。

2.2 顺位轮换

src/Core/GameState.ts AdvanceToNextPlayer()

  • 新增 InMainLoop = this._Phase === GamePhase.SelectMode 判断。
  • 仅在主循环且下一位回到 FirstPlayerIndex 时，RoundIndex += 1 并更新 FirstPlayerIndex。
  • 发射阶段、加赛阶段、开发过度后的重新发射均不触发轮次递增。

2.3 枯竭冲刺

src/Core/Occupation.ts Calculate(..., SprintBonus = 0)

  • 正向 RawGain 先加 SprintBonus，再乘以开发链倍率。
  • 负向 RawGain（倒扣）与 0（None）不加 Bonus。

src/Core/GameState.ts CalculateSprintBonus()

  • 三条件同时满足才生效：开关开启、公共 ≤ SprintThreshold、RawGain > 0。

2.4 配置与开关

src/Types/GameConfig.ts

  • CreateDefaultConfig：所有新开关 false，v1.1 兼容。
  • CreateVariantConfig：开启 LeaderTax / RotatingStart / ScarcitySprint；关闭 RevengeRaid。

三、模糊 / 冲突条目处理

条目 歧义/冲突 处理建议与最终选择
G-001 税额 Scale 清单提到 LeaderTaxScale 可选（领先每 10 点额外 +1）。 标准变体 不启用 Scale，仅 Base=1。Scale 保留为后续实验开关，避免过度压制领先者。
G-002 轮次定义 轮次从游戏开始计数，还是进入主循环后计数？NeedsRelaunch 玩家是否计入本轮？ 进入主循环后 RoundIndex=0；每所有 Active+Launched 玩家行动一次加 1；NeedsRelaunch 玩家本轮跳过，不触发轮次递增。
G-003 冲刺奖励倍率 Bonus 是在倍率前加还是倍率后加？ 先加 Bonus 再乘倍率：RawGain' = (RawGain + Bonus) × Multiplier。保证冲刺奖励也能被开发链放大。
G-004 复仇范围 本次是否实现复仇突袭？ 当前代码 已实现，但标准变体默认 关闭。复仇使用后清零连击；崩坏受害者并列时不发令牌。
