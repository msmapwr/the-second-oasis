1游戏概览

一句话定位与关键属性。

《第二绿洲》是一款面向 2~4 人 的网页策略桌游。玩家分别扮演四个国家，围绕月球（公共领土）展开领土争夺。游戏以掷骰为核心随机源，融合稳健 / 激进策略选择、连击开发的风险博弈，以及由抢夺升级而来的崩坏熔断机制。当公共领土被瓜分殆尽，私有领土最多者获胜。

网页端运行 2 ~ 4 人 回合制 掷骰驱动 风险 / 收益博弈 公共池衰减

2游戏背景与主题

地球资源枯竭后，人类将目光投向月球——代号"第二绿洲"。四个国家率先具备登月能力，意图在月球表面抢占尽可能多的领土。然而月球公共领土有限，争夺必然走向零和：当最后一块公共领土被分配完毕，谁在私人物业上积累最多，谁就掌握了新文明的主动权。

主题基调：冷峻的太空殖民竞争 + 轻策略博弈。视觉上建议采用深空蓝绿 + 月壤灰的配色，与计划书主色一致。

3游戏目标与胜负

胜利条件

当 公共领土归零（= 0） 时游戏立即结束，私有领土数值最高 的玩家获胜。平局时建议按"先达到该值者胜"或加赛一回合裁决（见待澄清 §15）。

失败 / 出局

常规情况下没有淘汰；但触发 开发过度（连续三次掷出对子）时，该玩家私有领土清零并标记为"荒地"，需重新走"发射"流程后才能再次参与占领。荒地不计入任何玩家领土，也不回归公共领土。

设计意图公共池是零和博弈的锚点：它越小，单次占领越容易触发抢夺与崩坏，对局在后段会显著加速并趋于混乱。

7基础机制：掷骰与占领

7.1 掷骰决定占领量

每回合玩家掷骰，点数为 n。常规 / 激进模式下 n 为双骰之和（2 ~ 12）；稳健模式下为单骰（1 ~ 6）。玩家本回合获得 n 点领土。

7.2 占领（特殊机制）

当玩家 (p) 执行占领 (m) 点领土时：

  • 公共领土 − m
  • 玩家 (p) 的私有领土 + m

也就是说，占领是把领土从公共池"搬"到私人名下。若 m 超过当前公共领土剩余量，则超出部分 m2 = n − 公共领土 触发抢夺（见 §10）。

举例公共领土剩 30，玩家掷出 n = 42（激进对子 + 开发 ×2 等组合后）。实际可占领上限为 30，溢出 m2 = 12 进入抢夺流程，由 (p) 向私有领土最高者发起争夺。

8回合开局：模式选择

每回合开始时，玩家可选择以下三种模式之一。模式决定本次掷骰的风险与收益：

稳健模式 SAFE

只掷 1 颗 骰子，获得 1 ~ 6 领土。
永不触发崩坏，收益低但稳定。

激进模式 RISK

掷 2 颗 骰子，获得 2 ~ 12 领土。
若点数的和 ≤ 6，则改为扣除相应点数并回归公共领土（即私有 − 点数，公共 + 点数）。

不开发 NONE

无明显效果（维持当前节奏，不主动触发开发链）。用于观望或规避风险。

规则缺口 · "不开发"原文将"不开发"列为第三种选择但注明"无效果"。本计划书将其理解为不主动选择开发链、按基础占领结算的中性选项；是否等同于"稳健"需确认（见 §15）。

9连击机制：开发链

当玩家掷出两个相同数字（对子）时，触发开发链。链的长度取决于连续掷出对子的次数：

连续对子次数触发效果
第 1 次开发本回合获得领土 ×2（翻倍）
第 2 次（连续）大开发本回合获得领土 ×3（翻三倍）
第 3 次（连续）开发过度私有领土 清零，标记为"荒地"（不计数、不回归公共），玩家需重新走发射流程
高风险高回报连续对子是强力的滚雪球手段，但第三次会直接清零——是典型的"见好就收"博弈点。建议在 UI 上对"连续对子计数"做醒目提示。
规则缺口 · 倍率基数原文"获得领土翻倍"未说明基数。本计划书推断为本回合应得领土（n 或模式点数）的倍率，而非私有总领土翻倍。若应为"私有总领土翻倍"需修改（见 §15）。

10特殊机制：抢夺

当玩家 (p) 的占领使公共领土不足以支付 n 时（公共 < m，推断 m=0），溢出部分 m2 = n − 公共领土 触发抢夺，由 (p) 发起。

10.1 抢夺流程

  1. 除 (p) 外，当前私有领土最高者 与 (p) 各掷一次骰。
  2. 若点数平手，则双方重新掷骰，直至分出高低。
  3. 点数更高者 获得 (m2 − r) 领土（r 为随机量，0 < r ≤ m2）。
  4. 点数更低者 减少 m2 领土。
  5. 差额 r 回归公共领土。
要点抢夺本质是"盈家与当前霸主"对溢出领土的裁决；r 作为损耗回归公共池，使公共领土有微量回血可能。
限制抢夺只能被触发一次。同一局中第二次尝试触发抢夺时，不再走抢夺流程，而是直接升级为 崩坏（见 §11）。

11特殊机制：崩坏

当抢夺被多次触发（即第二次本应触发抢夺时），系统进入崩坏状态——月球环境失衡，所有玩家共同受损。

11.1 崩坏结算

  1. 在所有玩家的私有领土中，各自随机减少一个介于 0 与 (x × m2) / 4 之间的数量。
  2. 发起崩坏的玩家 (p) 的私有领土，额外减少 (x × m2) − 其他玩家已减少的领土之和。
  3. 公共领土 − x（进一步萎缩）。
  4. 崩坏系数 x 初始为 2，每触发一次崩坏，x + 1。
规则缺口 · 随机减少的分配原文"在所有私人领土中随机减少一个 ≥0 且 ≤ (x·m2)/4 的数"语义偏模糊。本计划书推断为每位玩家独立随机损失 0 ~ (x·m2)/4，发起者再承担剩余缺口。若应为"全桌合计只减一个数"则需调整（见 §15）。
设计意图崩坏是惩罚"过度争夺"的熔断阀：x 随次数递增，意味着反复触发会让公共池与私人池同步塌缩，加速终局并制造大洗牌。

12特殊回合：发射

发射是游戏唯一的序章回合，仅在第一轮开始时进行。所有玩家必须先"发射"飞船，才能进入后续的领土抢占。

规则说明
触发时机仅游戏第一轮开始
发射条件掷双骰之和 ≥ 7 即发射成功，退出发射模式
发射奖励成功后私有领土 +2
失败处理发射失败者直接跳到下一玩家；下一回合继续尝试发射
成功处理发射成功者正常进入游戏循环
全员约束必须所有玩家都发射成功，占领阶段才开始
关联触发"开发过度"而被清零的玩家，需重新发射才能再次参与（参照本回合规则，掷 ≥7 恢复资格，成功后 +2）。

13网页实现要点

作为网页游戏，以下模块建议作为 MVP（最小可行产品）核心，对应上述每一条机制：

13.1 界面组件

组件对应机制说明
公共领土进度条§4 / §7 / §11实时显示 100→0，归零触发终局
玩家面板 ×4§4 / §7 / §9显示私有领土、连续对子计数、荒地标记
骰子区 + 掷骰按钮§7 / §8 / §12支持单骰（稳健）与双骰（激进/发射）
模式选择器§8稳健 / 激进 / 不开发 三态切换
抢夺 / 崩坏弹窗§10 / §11裁决动画 + 随机量 r 展示
行动日志全局记录每回合占领、开发、抢夺、崩坏

13.2 状态与随机数

  • 公共 / 私有领土应作为单一可信状态源（如前端 store 或后端权威房间），避免多端不一致。
  • r、崩坏随机损失等均需可复现的随机源；若含联机，随机种子应由服务器下发以保证公平。
  • 对子判定、连续计数需跨回合持久化（开发链状态机）。

13.3 技术建议

纯前端即可实现单人 / 同屏多人；若需联网对战，建议采用 WebSocket 房间 + 服务端权威结算。推荐栈：React/Vue + TypeScript + Canvas/SVG 进度条；后端 Node（与现有运行时一致）。

14术语表

公共领土
月球上所有玩家共享、可被瓜分的领土，初始 100，归零即终局。
私有领土
各玩家独立积累、决定胜负的最终数值，初始 0。
占领
把 m 点领土从公共池转移到自己私有名下。
抢夺
占领溢出公共池时，发起者与私有最高者裁决溢出量 m2 的特殊机制。
崩坏
抢夺被二次触发时的全局惩罚机制，系数 x 随次数递增。
开发 / 大开发
连续 1 / 2 次对子触发的领土 ×2 / ×3 奖励。
开发过度
连续 3 次对子触发，私有领土清零并标记荒地，需重新发射。
荒地
开发过度后私有领土的状态，不计数、不回归公共。
发射
首轮专属序章，掷 ≥7 成功方可参与占领，成功 +2。
r
抢夺中回归公共的随机损耗量，0 < r ≤ m2。
